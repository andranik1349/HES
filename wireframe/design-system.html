Working Memory and Cognitive Load

Definition

The capacity to hold and manipulate information in mind over short periods — the workbench of conscious thought. Underpins reasoning, comprehension, and the integration of incoming information with stored knowledge.

This element sits at the intersection of attention and long-term memory retrieval, acting as a bottleneck through which environmental inputs must pass before consolidation.

08 Accordion

The Human Elements System (HES) is a structured psychological framework organising human cognitive and emotional traits into 343 discrete elements across four layers: Core, Derived, Quantum, and Emotional. Each element is defined, measured, and assigned a Maturity/Measurability Level (MML).

Elements are classified by layer (Core, Derived, Quantum, Emotional), block (their functional grouping within the layer), and MML — a five-point scale from Established (MML-1) to Speculative (MML-5).

MML stands for Maturity/Measurability Level. It indicates the degree to which an element has been empirically validated. MML-1 elements are robustly established; MML-5 elements are speculative and may yet be refined or reclassified.
